# 要件定義書: ECカート 料金計算

- 正本: 本書（変更時は本書を更新し、Issue には本書へのリンクと受け入れ条件のみを書く）
- オーナー: PO ／ 最終更新: 2026-08-03

## スコープ

- カートの内容（商品リスト・会員フラグ・クーポン指定）を入力に、支払金額の内訳を返す料金計算ロジック
- 画面・DB・外部APIは本要件の対象外

## 機能要件

| ID | 要件 | 備考 |
|----|------|------|
| R-1 | 小計は「単価 × 数量」の全商品合計とする | |
| R-2 | 会員には非セール品の小計に対して 10% の割引を適用する | セール品は割引対象外。端数は切り捨て |
| R-3 | クーポン `COUPON500` は固定 500 円引きとする | 割引額は小計を上限とする（合計を負にしない） |
| R-4 | 会員割引とクーポンは併用できない | 両方指定はエラー |
| R-5 | 割引後金額が 5,000 円以上なら送料無料、未満は一律 500 円 | 5,000 円ちょうどは無料 |
| R-6 | 空カートは小計・割引・送料・合計すべて 0 円 | 送料を取らない |
| R-7 | 合計 = 割引後小計 + 送料 | |

## 異常系要件

| ID | 要件 |
|----|------|
| E-1 | 数量が 1 未満（0以下）・非整数の場合はエラー |
| E-2 | 単価が負・非整数の場合はエラー |
| E-3 | 無効なクーポンコードはエラー |
| E-4 | 会員割引とクーポンの併用指定はエラー |

## 非機能・制約

- 金額は整数（円）で扱う。浮動小数の誤差を計算結果に持ち込まない
- 料金計算は外部 I/O に依存しない純粋関数とする（テストの決定性のため）
- 異常系は専用エラー `PricingError` を throw で表現する（null や -1 で表現しない）
