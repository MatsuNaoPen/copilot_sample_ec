# お題 Issue（大）: 割合クーポン RATE10 の追加

> 研修用の発注書 Issue 下書き。GitHub の Issue テンプレート（task）に転記して使用する。
> 設計書の更新 → 実装 → テスト生成までの一気通貫を体験する題材。想定所要: 40〜50分

## 目的（1〜2行）

固定額クーポンに加えて割合型クーポンを導入し、高額購入者向けの販促を可能にする。

## スコープ

- `src/lib/pricing.ts` へのクーポン種別（割合型）の追加と、テストの追加
- `docs/design.md` への仕様追記（クーポン種別の表・受け入れ条件）
- カート画面（`app/cart/page.tsx`）は既存のクーポン入力欄をそのまま使う

**やらないこと:**

- クーポンの併用（複数クーポン同時利用）対応
- クーポンの有効期限・発行管理

## 受け入れ条件

- [ ] クーポンコード `RATE10` を追加する: **小計の10%引き・割引上限 1,000円**
- [ ] 端数は切り捨てる（例: 小計 999円 → 割引 99円）
- [ ] 割引上限の境界: 小計 10,000円 → 割引 1,000円／小計 10,001円 → 割引 1,000円（上限適用）
- [ ] `COUPON500` の既存挙動は変えない
- [ ] 会員割引との併用不可ルールは `RATE10` にも適用される（併用指定はエラー）
- [ ] 無効クーポンのエラー挙動は変えない
- [ ] 追加仕様が `docs/design.md` に反映されている（クーポン表・受け入れ条件）
- [ ] 上記すべてに対応するテストが `tests/pricing.test.ts` に追加され、全テストグリーン

## 制約

- 計算ロジックは `src/lib/pricing.ts` の純粋関数のまま維持する
- クーポン定義は種別（固定額/割合）を表現できるデータ構造に拡張してよいが、公開インターフェース
  （`calculateCharge` / `Cart` / `PricingResult`）の互換は維持する

## 正本リンク（背景参照用）

- 要件: docs/requirements.md（R-3・R-4）
- 設計: docs/design.md
