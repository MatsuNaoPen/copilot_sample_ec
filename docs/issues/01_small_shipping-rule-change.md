# お題 Issue（小）: 送料ルールの変更

> 研修用の発注書 Issue 下書き。GitHub の Issue テンプレート（task）に転記して使用する。
> 想定所要: 発注書化 10分＋委譲・レビュー 20分程度

## 目的（1〜2行）

キャンペーン施策として送料無料のハードルを下げ、カート離脱を減らす。

## スコープ

- `src/lib/pricing.ts` の送料計算の定数変更と、それに伴うテストの更新
- `docs/design.md` の定数表の更新

**やらないこと:**

- 割引ロジック（会員割引・クーポン）の変更
- UI 文言の変更

## 受け入れ条件

- [ ] 送料無料のしきい値を 5,000円以上 → **3,000円以上** に変更する
- [ ] 通常送料を 500円 → **600円** に変更する
- [ ] 割引後ちょうど 3,000円 は送料無料になる（境界値テストを更新）
- [ ] 割引後 2,999円 は送料 600円 になる（境界値テストを更新)
- [ ] 既存テストがすべてグリーン（しきい値変更の影響を受けるケースは期待値を更新）
- [ ] `docs/design.md` の定数表が新しい値に更新されている

## 制約

- 計算ロジックは `src/lib/pricing.ts` の純粋関数のまま維持する
- 定数の変更は名前付き定数（`FREE_SHIPPING_THRESHOLD` / `SHIPPING_FEE`）の値変更で行う

## 正本リンク（背景参照用）

- 設計: docs/design.md（定数表・受け入れ条件）
