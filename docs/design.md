# 設計書: ECカート 料金計算

- 上位文書: [docs/requirements.md](requirements.md)
- オーナー: エンジニアリード ／ 最終更新: 2026-08-03

## 技術設計

- 実装場所: `src/lib/pricing.ts`（純粋関数）。UI（`app/`）はこの関数を呼ぶだけにする
- 公開インターフェース: `calculateCharge(cart: Cart): PricingResult`
- エラー: `PricingError`（`Error` 継承）。UI 側で捕捉してメッセージ表示する
- テスト: `tests/pricing.test.ts`（Vitest・node 環境）

## 計算順序

1. バリデーション（E-1〜E-4。順序: 数量/単価 → 併用 → クーポン有効性）
2. 小計 = Σ(単価 × 数量)
3. 割引 = 会員なら `floor(非セール品小計 × 10%)`、非会員でクーポンありなら `min(500, 小計)`
4. 送料 = 空カート: 0 ／ 割引後 ≥ 5,000: 0 ／ それ以外: 500
5. 合計 = (小計 − 割引) + 送料

## 受け入れ条件（機能設計）

- [ ] 単品 1,000円 × 2 ＋ 非会員 → 小計2,000・割引0・送料500・合計2,500
- [ ] 空カート → すべて0
- [ ] 会員・非セール3,000円 → 割引300
- [ ] 会員・非セール3,000円＋セール2,000円 → 割引300（セール品は対象外）
- [ ] 会員・999円 → 割引99（端数切り捨て）
- [ ] COUPON500・小計2,000円 → 割引500
- [ ] COUPON500・小計300円 → 割引300（小計を上限）
- [ ] 割引後ちょうど5,000円 → 送料0
- [ ] 割引後4,999円 → 送料500
- [ ] 数量0・数量負・単価負・無効クーポン・併用指定 → PricingError

## 定数（変更時は本書と実装・テストを同時に更新する）

| 定数 | 値 | 実装箇所 |
|------|-----|----------|
| 会員割引率 | 10% | `MEMBER_DISCOUNT_RATE` |
| クーポン | COUPON500 = 500円 | `VALID_COUPONS` |
| 送料無料しきい値 | 5,000円（以上で無料） | `FREE_SHIPPING_THRESHOLD` |
| 通常送料 | 500円 | `SHIPPING_FEE` |
