# ADR-0001: 料金計算を純粋関数として実装する

- ステータス: 採用
- 日付: 2026-08-03

## 文脈

料金計算はこのプロダクトで最も不具合の影響が大きいロジックであり、テストで正しさを担保し続けたい。
また、AI エージェント（GitHub Copilot Coding Agent）に改修を委譲する際、決定的に検証できる構造が必要。

## 決定

料金計算を `src/lib/pricing.ts` に外部 I/O（ネットワーク・DB・現在時刻・乱数・DOM）へ依存しない
純粋関数として実装し、UI からはこの関数を呼ぶだけにする。

## 比較した選択肢

1. コンポーネント内で直接計算 — 実装は速いがテストが UI に結合し、エージェントの変更検証が不安定になる
2. API サーバー側で計算 — 本デモの範囲では過剰。デモ環境の可搬性が下がる
3. **純粋関数として分離（採用）** — テストが決定的・高速。受け入れ条件をそのままテスト化できる

## 影響

- テストは `tests/pricing.test.ts` に集約され、CI ゲートの主対象になる
- 仕様変更は docs/design.md の受け入れ条件 → テスト → 実装の順で反映する
